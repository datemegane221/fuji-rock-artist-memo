# 気になるアーティストメモ

好きなイベント（フェス・ライブなど）で気になるアーティストを記録するための個人用メモアプリ。

## 機能

- アーティスト名、イベント名（自由入力）、メモ、ステージ（自由入力）、日程（自由入力）を記録
- 評価（殿堂入り / また観たい / 気になる / チェック中）でランク付け
- イベントでの絞り込み、評価順・名前順での並び替え
- Spotify / YouTube リンクの保存、Google検索へのショートカット
- ブラウザの `localStorage` にデータを保存（バックエンドなし）

### データ移行について

以前のバージョン（フジロック専用・ステージ/日程が固定選択式）で保存したデータは、
初回起動時に自動でイベント名「FUJI ROCK FESTIVAL」・自由入力形式のステージ/日程に変換されます。
旧データ（`localStorage` の `fujirock:artists:v1`）はそのまま残るため、失われる心配はありません。

## 開発

```bash
npm install
npm run dev
```

`http://localhost:5173` で起動します。

## ビルド

```bash
npm run build
npm run preview
```
